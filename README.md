# Qurilish Radar

O'zbekiston bo'ylab yangi qurilish va novostroykalarni topib, quruvchisi (potensial mijoz)
bilan Telegram'ga xabar beradi. Ijara (lesa/opalubka) biznesi uchun mijoz jalb qilish vositasi.

## Railway sozlamalari (Variables)
- `BOT_TOKEN` — @BotFather dan olingan bot tokeni (majburiy)
- `OWNER_ID` — xabar keladigan Telegram ID (default 7589459697)
- `CHECK_HOURS` — necha soatda tekshirsin (default 3)

## Buyruqlar
- `/test` — hoziroq tekshirib ko'rish (nima topilganini ko'rsatadi)
- `/oxirgi` — oxirgi topilganlar
- `/id` — Telegram ID

## Manbalar
- Rasmiy/ommaviy yangiliklar (gazeta.uz, spot.uz, kun.uz, uza.uz) — qurilish xabarlari
- uysot.uz — novostroyka + quruvchi (best-effort)
- (keyingi bosqich: Shaffof qurilish rasmiy reestri, AI rasmdan bosqich aniqlash)
